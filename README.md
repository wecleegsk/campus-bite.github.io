# Campus Bite

Browse menus, place orders, and choose collection or delivery from a phone or computer.

**Live site:** https://wecleegsk.github.io/campus-bite.github.io/

## Problem

Long queues, limited time between classes, missed meals, hard-to-find vendors, tight budgets,
and limited access to campus essentials (e.g. stationery, calculators) during peak periods.

## Solution

A user-friendly web platform with online ordering, collection and delivery options,
vendor information, affordable meal options and tutoring/study-session booking.

## Tools and technologies

- HTML, CSS and JavaScript (no framework)
- Cart stored in the browser with `localStorage`
- Orders sent through WhatsApp (`wa.me` links)
- Hosted on GitHub Pages
- Font Awesome and Google Fonts via CDN

## Planned AI integrations

Proposed for future development (not yet built):

- AI chatbot for menu, price and opening-hours questions
- Order assistant that turns a chat message into a cart
- Budget finder that suggests the cheapest meal for a given amount
- Automated order confirmations
- Demand insights for vendors

## Running locally

Clone the repo and open `index.html` in a browser. No build step.
